# DrLilo releases

Public download files and release metadata for the DrLilo Mac app. Application and website source code are maintained separately in private repositories.

- [DrLilo website](https://www.drlilo.com)
- [Download the latest Mac beta](https://www.drlilo.com/download)
- [Release downloads](https://github.com/philinscience/drlilo-releases/releases)

The Mac beta supports Apple Silicon and macOS 13 or later. Installers are signed with Developer ID and notarized by Apple. This repository contains release binaries and metadata only; no license to the application source code is granted here.
